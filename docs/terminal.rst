The Terminal
#######################

It is our hope that 99.9% of what you have to do on your computer you can do without the Terminal (The Linux equivilent of CMD)

Sometimes you will be asked to input commands that you don't understand, This page is meant to explain a few basic commands and show how they might be useful.

Moving around and creating files
================================

Opening up the terminal brings up a prompt that shows::

	Username@ComputerName:~$

You start on your home folder when you open up the terminal, You can list the files and folders inside of the Home folder with the command "ls".

Folders (or as they're called in the terminal, Directories) are colored blue to stand out from indvisual files and programs.

If you want to access what's inside another folder, you can use the command "cd [name of directory]", as in Change Directory

Creating a file is as simple as doing "touch [name of file with extention]"

.. hint:

	One of the neat things about the terminal is that you can do large amounts of operations all at once with &&. For example, You can make a website folder and files for it with "mkdir server && cd server && touch index.html style.css"
